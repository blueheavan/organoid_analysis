## Acceptance

| A6 | Exploratory classifier leakage | Missing values, CV train/validation split, model selection | Learned preprocessing fits training subset per fold; model choice uses training CV, not holdout score. No biological/generalization claim from object splits. |
| A7 | Packaging / runtime | Build wheel, install isolated target, bundled offline viewer, CLI, exports | Artifact imports and bundled resource resolve without source-tree fallback; retain hashes. |
| A8 | Full engineering QA | Existing full tests, explicit native render, lint, format check, mypy, notebooks, smoke | Record actual exit/count/skip/failure; never relax checks or recast skipped work as PASS. |

Demo generated by this project is not independent biological evidence. |
| A10 | Real data / inferential readiness | Inventory current local data and model assets | Real validation requires qualified independent annotations/assay, study independence, justified N and precision, strata and held-out calibration. Where absent: INSUFFICIENT EVIDENCE; no invented N or criterion. |

New reproduced defects may add targeted tests against the above invariants;
no algorithm, biological threshold, intended use or statistical method is tuned
to obtain PASS. Computational failure and missing scientific support remain distinct.
Review separation: Tier D, LIMITED INDEPENDENCE (same agent/context); analytical
and definitional oracles are separate from reviewer independence.
